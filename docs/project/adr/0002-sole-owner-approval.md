# ADR-0002 — Use Sole Owner Approval for This Repository

## Context

The repository is maintained by one accountable owner, Rezar86. Requiring a second
human approval is not workable for this project.

## Decision

For this repository only, explicit approval from Rezar86 is sufficient for Tier 1
merge and release decisions. The shared process documents remain unchanged.

## Consequences

The owner carries the approval responsibility. Reviews, verification, rollback notes,
and existing security controls remain required.
